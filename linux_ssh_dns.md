## Основные команды Linux

- `pwd` - текущий каталог.
- `ls -la` - список файлов, в том числе скрытых, с правами доступа.
- `cd путь` - перейти в каталог; `cd ..` - на уровень выше.
- `mkdir -p practice/logs` - создать каталоги.
- `cp source.txt copy.txt` - скопировать файл.
- `mv copy.txt notes.txt` - переместить или переименовать файл.
- `cat notes.txt` - вывести содержимое.
- `nano notes.txt` - открыть текстовый редактор.
- `rm notes.txt` - удалить файл; это не перемещение в корзину.
- `sudo команда` - выполнить отдельную команду с правами администратора.

Команды `rm` и `sudo` применяют после проверки пути и назначения операции.

## SSH

SSH обеспечивает защищённый удалённый доступ: шифрует канал, проверяет сервер и аутентифицирует клиента. Асимметричные ключи используются при согласовании и аутентификации; данные сеанса передаются с помощью быстрых симметричных алгоритмов. Приватный ключ хранится на клиенте, публичный - на сервере. Отпечаток ключа сервера следует проверять перед первым подключением.

## DNS

DNS сопоставляет имена и записи: A - IPv4, AAAA - IPv6, CNAME - псевдоним, MX - почтовый сервер, TXT - текстовые данные, NS - авторитетный сервер зоны. Рекурсивный резолвер получает ответ от авторитетных серверов и кэширует его на время TTL. DNS сам по себе не создаёт защищённого SSH-канала.

## Виртуализация на этом компьютере

Архитектура Mac - arm64 (Apple Silicon). Для виртуальной машины нужен образ Ubuntu Server ARM64. Пункт методички о BIOS VT-x/AMD-V относится к x86-компьютерам; на Apple Silicon такой настройки BIOS нет.

Скачаны официальные файлы VirtualBox для macOS ARM64 и Ubuntu Server 22.04.5 ARM64. Установка VirtualBox требует системной авторизации администратора macOS. Виртуальная машина в задании №4 пока не требуется: это подготовка к занятию №5.
