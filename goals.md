# Цели на семестр

1. Освоить Git: до конца блока выполнить ветвление, Pull Request, rebase, разрешение конфликтов, cherry-pick и revert.
2. Контейнеризировать Python-приложение: написать Dockerfile, собрать образ и запустить его локально.
3. Настроить CI/CD в GitHub Actions: автоматически запускать тесты при каждом Pull Request и собирать образ после слияния.

## Почему нельзя писать всё в main

Общая ветка должна оставаться работоспособной. Изолированные feature-ветки и Pull Request позволяют проверять изменения, обсуждать решения и запускать тесты перед интеграцией.
