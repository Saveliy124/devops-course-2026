# Git в VS Code и терминале

## Три удобные возможности VS Code

1. Source Control показывает изменённые файлы и позволяет открывать построчный diff.
2. Можно добавлять в индекс отдельные изменения и создавать коммит, не переключаясь из редактора.
3. Граф истории и GitLens помогают проследить автора и причину изменения строки.

## Что удобнее в терминале

Interactive rebase: в терминале явно видны диапазон коммитов, команды reword/fixup/drop и состояние незавершённой операции.
