# Мой пет-проект

Идея: Telegram-бот для учёта личных расходов. Пользователь добавляет сумму и категорию, а бот показывает расходы за день и месяц.

Стек: Python, aiogram, SQLite, pytest, Docker, GitHub Actions.

Цель: научиться разрабатывать и тестировать Python-приложение, хранить данные в SQLite и автоматически проверять изменения в CI.
