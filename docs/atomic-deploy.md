# Факультативный атомарный деплой

scripts/deploy-atomic.sh создаёт релиз в /var/www/devops-site/releases/,
применяет --link-dest и D755,F644, переключает current через ln -s и mv -T,
сохраняет до пяти версий. --rollback меняет current на previous.
Подготовка использует один вызов ssh; rsync использует второй. Переключение
и удаление старых версий выполняет atomic-receiver.sh после успешного rsync
в рамках того же соединения. Приёмник установлен в ~/devops-course-2026/scripts/.

Профиль Nginx: config/nginx-devops-site-atomic.conf. Основной профиль
nginx-devops-site.conf и основной scripts/deploy.sh сохранены для обычного
деплоя и следующих работ. Полный факультативный стенд сохранён в снимке
05a-atomic-web-deploy. Перед КР2 рабочий стенд возвращён к основному профилю.

ln -sfn сначала удаляет старую ссылку, поэтому между удалением и созданием
ссылка отсутствует. Переименование готовой временной ссылки через mv -T
в пределах той же файловой системы атомарно заменяет имя current.

Символические ссылки имеют условные права 777; они не дают право изменять
их целевые файлы. Аудит проверяет реальные файлы и каталоги, исключая этот
ложный признак world-writable у symlink.
