## 1. Какую проблему решает DevOps?

Разрыв между разработкой и эксплуатацией: разные цели, ручные передачи и медленные нестабильные релизы. DevOps объединяет ответственность за продукт и автоматизирует сборку, проверку, доставку и наблюдение.

## 2. Что означает CALMS?

Culture - культура сотрудничества; Automation - автоматизация; Lean - сокращение потерь и небольшие партии изменений; Measurement - измерение результата; Sharing - обмен знаниями.

## 3. Чем отличаются git add и git commit?

git add помещает выбранное содержимое в индекс. git commit создаёт коммит из текущего индекса с родителем, метаданными автора и сообщением.

## 4. Зачем нужен SSH-ключ?

Клиент доказывает владение приватным ключом, не передавая его серверу. На сервер загружается только публичная часть. Пароль от аккаунта не требуется при каждом push; приватный ключ следует хранить локально и при необходимости защищать парольной фразой.

## 5. Что означают origin и main?

origin - имя настроенного удалённого репозитория, main - имя локальной ветки. git push origin main отправляет эту ветку в соответствующую ветку удалённого репозитория.

## 6. Назовите метрики DORA из задания.

Частота развёртываний; время от изменения до продакшена; доля неудачных изменений; время восстановления сервиса. В отчёте используется набор из четырёх метрик, приведённый в методичке.
